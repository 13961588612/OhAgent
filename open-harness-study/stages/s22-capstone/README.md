# s22 · 毕业项目：企业级智能体平台

> 前置：全部阶段 ｜ 建议投入：40–60h ｜ 难度：★★★★★

## 一、项目目标

基于 OpenHarness 交付一个**可上线**的企业级 Agent 后端 MVP，覆盖：统一模型接入、能力治理、安全边界、记忆与成本、多智能体、IM 交付、可观测、部署运维。

工作区：`../../capstone/`（结构见该目录 README）。

## 二、需求范围（必须全部满足）

| 编号 | 需求 | 对应阶段 |
|------|------|----------|
| R1 | **模型网关**：至少 1 个 Anthropic 兼容 + 1 个 OpenAI 兼容 profile，按业务线隔离凭据，模型白名单 | s02 |
| R2 | **能力治理**：≥3 个企业 Skill、≥1 个企业 Plugin（含工具 + 钩子 + MCP）、≥2 个内部 MCP Server | s08 s09 s10 |
| R3 | **安全边界**：权限基线（路径/命令/工具）、沙箱隔离、审计钩子全留痕 | s06 s07 s18 |
| R4 | **记忆与成本**：项目约定 + 记忆库 + 自动压缩阈值调优 + 成本护栏 | s11 s12 |
| R5 | **多智能体**：≥3 个专家 AgentDefinition，一次真实并行任务（含 worktree 隔离） | s13 s14 |
| R6 | **IM 交付**：≥1 个通道端到端可用，支持长任务进度反馈 | s16 |
| R7 | **可观测**：审计日志 + 3 个核心指标 + 一份事故手册 | s19 |
| R8 | **质量与发布**：测试门禁、可构建分发版、部署与升级说明 | s20 s21 |

## 三、交付物清单

1. **代码**：`capstone/` 下的配置、插件、MCP Server、技能、钩子、脚本。
2. **文档**：架构说明（含数据流图）、部署手册、运维手册（含事故处置）、使用者指南。
3. **证据**：关键实验的命令与输出（脱敏）、测试报告、成本统计样例。
4. **答辩**：15 分钟讲解 + 30 分钟问答（问题来自本路线各阶段的"进阶思考"）。

## 四、验收标准（逐项打勾）

- [ ] `oh --dry-run` 在标准环境下输出 `ready`（或可解释的 warning）。
- [ ] 一条完整业务链路可跑通：IM 消息 → 权限校验 → 沙箱内工具执行 → 记忆检索 → 结果回传。
- [ ] 越权尝试（越界写文件、内网访问、危险命令）全部被拦截并有审计记录。
- [ ] 多智能体并行任务产出可合并的代码/文档，且过程可追溯。
- [ ] 成本可归集到"项目/团队/会话"维度，且超阈值可告警。
- [ ] 构建产物可在干净环境安装运行；升级步骤可复现。
- [ ] 你能在 5 分钟内为一次人为注入的故障定位到模块并给出修复方案。

## 五、加分项（冲击资深水平）

- 为 OpenHarness 贡献一个上游可接受的 PR（新工具/新 provider/文档/测试）。
- 实现一个"分布式 cron 主选举"，解决多副本重复执行问题。
- 实现跨进程的全链路 trace（主 Agent ↔ 队友 ↔ 子进程）。
- 为"技能命中率"建立可量化的评估集与报告。
- 把沙箱后端替换为 K8s Job，并给出成本/隔离性对比。

## 六、答辩必答题

1. 画出你平台的完整架构图，并指出哪些是上游能力、哪些是自研。
2. 你的权限与审计设计，能否抵御"模型被提示注入后试图越权"？
3. 一次上下文爆炸 + 一次成本飙升，你的定位路径分别是什么？
4. 如果业务量涨 10 倍，你的系统第一个瓶颈在哪？怎么解决？
5. 哪些上游改动会让你最痛？你的适配策略是什么？

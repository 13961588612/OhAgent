# 笔记区

这里放**你自己的**理解、源码摘录、实验输出与踩坑记录。不要抄文档原文，要写"我能复述的原理 + 我验证过的现象"。

## 命名约定

```
notes/
├─ s00-环境与源码地图.md
├─ s04-引擎阅读.md
├─ s05-自定义工具实验.md
└─ 主题-<关键词>.md        # 跨阶段专题，如 主题-企业网关选型.md
```

> 执行中的骨架用 [`_模板-阶段工作笔记.md`](_模板-阶段工作笔记.md)：按 RUNBOOK 的步骤分段，
> 每段只写"做什么"（动作与命令），结论、数字和判断一律留空，做完自己填。

## 每份笔记建议结构

（下面是**写完之后**的形状；执行过程中的逐步骤记录见上面的模板。）

```markdown
# <阶段号> <主题>

## 1. 源码地图
- 文件 / 符号 / 一句话职责（附源码路径）

## 2. 我理解到的机制
（用"输入 → 处理 → 输出"描述，不用照抄注释）

## 3. 实验与证据
```powershell
# 执行的命令
```
（贴关键输出片段）

## 4. 疑问与待验证
- [ ] 问题 → 验证方式

## 5. 企业视角
这条能力放进公司平台，缺口在哪里？
```

## 自检三问（每阶段结束必须能回答）

1. 这个机制**为什么**要这么设计？替代方案是什么？
2. 我能否**不看源码**画出一张调用顺序图？
3. 如果上游改版，我如何快速定位受影响的位置？
